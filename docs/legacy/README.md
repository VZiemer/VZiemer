# Legacy / Histórico

Public historical projects retained as engineering references. The `legacy` topic describes their role in this portfolio; it does not archive a repository or assert that the code is useless.

| Project | Historical purpose | Current scope |
| --- | --- | --- |
| [Bemafi32](https://github.com/VZiemer/Bemafi32) | Node.js FFI wrapper around the Bematech fiscal-printer DLL, with receipt and report operations | Historical integration; current Node.js, driver and device compatibility have not been validated |
| [NFeJS](https://github.com/VZiemer/NFeJS) | Earlier Node.js work around NF-e XML and related Brazilian fiscal integrations | Historical reference with existing public adoption; not a claim of current fiscal compliance or supported production operation |

Original repository URLs, branches and history are retained. Review each project's license, dependencies and operational requirements before reuse. No repositories were archived as part of this portfolio refresh.

This public index intentionally omits private repositories and repositories whose ownership, sensitive data or maintenance status still needs review.
