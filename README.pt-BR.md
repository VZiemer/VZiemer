# Vanius Ziemer

**Engenheiro de Software Sênior · Arquiteto de Software · Cloud e Sistemas Distribuídos**

Sou engenheiro de software com **mais de 12 anos de experiência profissional** projetando, desenvolvendo, modernizando e sustentando sistemas. Gosto de entender o problema de negócio antes de escolher a tecnologia e priorizo **arquiteturas claras, manutenibilidade e resultados mensuráveis**, evitando complexidade desnecessária.

Minha experiência inclui desenvolvimento full stack, sistemas cloud-native, liderança técnica, troubleshooting em produção, otimização de performance e colaboração com equipes internacionais. Atualmente exploro **agentes de IA, integrações com LLMs e engenharia de segurança** em projetos independentes.
