# Vanius Ziemer

**Senior Software Engineer · Software Architect · Cloud & Distributed Systems**

I am a software engineer with **12+ years of professional experience** designing, building, modernizing, and operating software systems. I enjoy understanding the business problem before choosing the technology, and I prioritize **clear architectures, maintainability, and measurable results** over unnecessary complexity.

My experience includes full-stack engineering, cloud-native systems, technical leadership, production troubleshooting, performance optimization, and collaboration with international teams. I currently explore **AI agents, LLM integrations, and security engineering** through independent projects.
